# A Literacia — GitHub Pages

Pacote de especificação simples para construir **A Literacia** como website estático alojado em GitHub Pages.

## Objetivo

Criar uma plataforma educativa extremamente simples, visual, responsiva e gamificada sobre competências essenciais para a vida.

Literacias incluídas:

1. Literacia Financeira
2. Literacia Digital
3. Literacia Alimentar
4. Literacia Científica
5. Literacia Ambiental
6. Literacia Jurídica
7. Literacia Mediática
8. Literacia Cívica
9. Literacia de IA
10. Literacia de Segurança e Autoproteção

## Filosofia técnica

Evitar arquitetura excessiva.

Preferir:

- HTML
- CSS
- JavaScript
- JSON estático

Sem:

- backend;
- autenticação;
- base de dados;
- APIs obrigatórias;
- frameworks pesados.

O progresso pode ser guardado com `localStorage`.
