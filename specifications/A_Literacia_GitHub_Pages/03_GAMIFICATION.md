# GAMIFICAÇÃO — A LITERACIA

# Filosofia

O site deve parecer um jogo educativo, mas o conhecimento é o jogo.

Evitar transformar o produto numa máquina de dopamina.

---

# XP

Sugestão:

```text
Lição concluída       +20 XP
Quiz concluído        +10 XP
Missão concluída      +25 XP
Desafio final         +50 XP
```

Repetir infinitamente não deve gerar XP ilimitado.

# Missões

As missões transformam conhecimento em decisões.

Exemplos:

### Financeira

**Tens 50 €. Como divides?**

### Digital

**Esta mensagem é phishing?**

### Alimentar

**Constrói uma refeição equilibrada.**

### Científica

**Qual destas afirmações é evidência?**

### Ambiental

**Qual escolha produz menos desperdício?**

### Jurídica

**Contrato, regra ou direito?**

### Mediática

**Notícia, opinião ou publicidade?**

### Cívica

**Que instituição trata deste problema?**

### IA

**A resposta da IA parece convincente. Como a verificas?**

### Segurança

**Estás num local desconhecido e sentes-te inseguro. Qual é a decisão mais prudente?**

---

# Desafio final

Cada literacia termina com um cenário.

Exemplo:

```text
DESAFIO FINAL — VIDA REAL
```

Não precisa de ser chamado Boss Quiz se a UI ficar demasiado infantil.

# Sem punição

Não utilizar:

- perder XP;
- vidas;
- penalizações;
- regressar todos os dias obrigatório.

Falhar é parte do conteúdo.
